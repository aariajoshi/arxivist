# Dataset: WMT 2014 English-German

This directory should contain the WMT 2014 English-German dataset.
To download and preprocess the data, please follow these instructions.

The dataset is publicly available. You can download the raw data from statmt.org or use a dataset library like HuggingFace `datasets`.

Directory Structure after download:
```
data/
  raw/
    train.en
    train.de
    ...
  processed/
    train.en.bpe
    ...
```
