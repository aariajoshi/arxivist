# Data

No external dataset is required by this paper or this repository. Every benchmark used in
Section 6 (Ornstein-Uhlenbeck process, smooth constant-coefficient advection-diffusion,
unresolved-front plateau) is generated synthetically from closed-form initial conditions and
drift/diffusion coefficients -- see `src/fcdf_diagonal_frog/benchmarks/`.

`download.sh` is a no-op, kept only for ArXivist repo-template consistency.
