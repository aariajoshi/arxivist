## What This Does

Current video diffusion models produce beautiful frames but physically wrong motion — objects rubber-stretch, rotations reverse mid-clip, zooms appear abruptly. This repository adds a **drop-in frequency-domain regulariser** to any video diffusion training loop that penalises these violations without touching the backbone architecture.

The core insight: basic rigid motions (translate, rotate, scale) leave **simple, detectable fingerprints in the frequency domain** via the SIM(2) spectral manifold:

```
ωt + vx·ωx + vy·ωy + Ω·m + α·ν + b₀ = 0
```

Three lightweight losses enforce these signatures, needing only **2.7% of spectral coefficients** (the lowest-frequency cube) while capturing **97%+ of video energy**.

## Quick Start

```python
from physics_motion_loss import PhysicsMotionLoss

loss_fn = PhysicsMotionLoss()   # all defaults from paper

# In your diffusion training loop:
out = loss_fn(x0_hat)           # x0_hat: [B, C, T, H, W]
total_loss = denoising_loss + 0.1 * out['loss']
total_loss.backward()
```

### Data Flow

```
x̂₀ [B, C, T, H, W]
    │
    ├── (per channel, per batch item)
    │
    ▼
3D FFT + Hann window → Spectrum [T, H, W] complex
    │
    ▼
Low-pass cube (ϱ=0.3) → [T_lp, H_lp, W_lp]  (2.7% coefficients, 97% energy)
    │
    ├──────────────────┬─────────────────────────────┐
    ▼                  ▼                             ▼
ℒ_trans            ℒ_rot                         ℒ_scale
WLS plane fit      Polar→AngularDFT→TempDFT      Ring energies
(ωx,ωy,ωt)        Ring entropy + Tilted-line     Grad alignment + Centroid trend
    │                  │                             │
    └──────────────────┴─────────────────────────────┘
                        │
                        ▼
            Adaptive softmax weighting (τ=0.1)
                w_i = exp(−L_i/τ) / Σ exp(−L_j/τ)
                        │
                        ▼
                    ℒ_motion (scalar)
                        │
                        ▼
        total_loss = ℒ_denoising + 0.1 × ℒ_motion
```
