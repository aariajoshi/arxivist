# D3LM — Reproduction

**Paper:** [D3LM: A Discrete DNA Diffusion Language Model for Bidirectional DNA Understanding and Generation](https://arxiv.org/abs/2603.01780)
**Authors:** Zhao Yang, Hengchang Liu, Chuan Cao, Bing Su (Renmin University of China; Zhongguancun Academy) — MLGenX 2026

> *Generated by ArXivist from SIR `arxiv_2603_001780`. Independent reproduction, not the authors' official code.*

## What this paper does (plain English)

D3LM unifies **DNA understanding and generation** in one model via **masked diffusion**. BERT-style
models (NT, DNABERT) are bidirectional but can't generate; autoregressive models (HyenaDNA, Evo)
generate but only left-to-right, which is wrong for DNA where regulation is bidirectional
(enhancers act from up- *and* down-stream). D3LM keeps NT-v2's bidirectional attention but swaps the
fixed-15%-mask objective for **variable-ratio masked diffusion**: mask each token with probability
`t ~ U[0,1]`, predict the clean tokens with a **1/t-weighted cross-entropy** (Eq 2), and **generate**
by iteratively unmasking an all-`[M]` sequence over T=50 steps (Eq 4).

Two variants: **D3LM** (initialized from pretrained NT-v2, best for understanding) and **D3LM-R**
(random init, best for generation). D3LM-R reaches **SFID 10.92** on 2048bp regulatory-element
generation — close to real DNA (7.85) and far ahead of HyenaDNA (29.16), DiscDiff (62.74), Evo (1360).

This repo **loads the official weights** (`Hengchang-Liu/D3LM-*` on HuggingFace) to generate + evaluate,
and ships a **from-scratch, CPU-testable** implementation of the masked-diffusion algorithm.

## ⚠️ Weights & hardware

- The masked-diffusion algorithm, tokenizer, and unit tests run **on CPU** — no GPU, no custom kernels.
  `pytest tests/ -q` verifies the paper's objective (Eq 2) and sampler (Eq 4) exactly.
- Official weights load via `AutoModelForMaskedLM(trust_remote_code=True)`. Generation of 2048bp
  sequences is much faster on GPU (Colab T4) but works on CPU for small runs.
- **SFID** (the headline metric) needs the pretrained **Sei** genomic CNN; the repo computes cheap
  **real** metrics (GC ratio, diversity, novelty, motif correlation) without it, and SFID if Sei loads.

## Quick start

```bash
pip install -e .
pytest tests/ -q                                    # verify the algorithm (CPU)
python data/download.py --weights D3LM-R            # official generation weights
python generate.py --config configs/config.yaml --n 100 --out results/gen.fasta
python evaluate.py --config configs/config.yaml --generated results/gen.fasta
```
Without weights/data, the pipeline falls back to a from-scratch sampler + a clearly-labeled
synthetic dataset so it still runs (those numbers are not comparable to the paper).

## Verify the algorithm (no GPU, no weights)

```bash
pytest tests/ -q
```
Checks: 6-mer vocab (4096 + specials); N/6 tokenization; forward masking masks ~t; the **1/t loss
scales exactly as 1/t** and scores only masked positions (Eq 2); **generation recovers an oracle
target with zero leftover masks** (Eq 4); GC ratio / diversity / novelty / motif correlation.

## Generate / Evaluate

```bash
python generate.py --config configs/config.yaml --n 1000 --length 2048   # D3LM-R, T=50, tau=1.1
python generate.py --config configs/config_debug.yaml --dry-run          # build only
python evaluate.py --config configs/config.yaml --generated results/generated.fasta
```

## Reproducibility notes

- **Algorithm from scratch, verified:** the 1/t-weighted CE (Eq 2) and iterative unmasking (Eq 4) are
  unit-tested on CPU (oracle recovery, exact 1/t scaling) — the paper's core is checked, not assumed.
- **Official weights** load via `trust_remote_code`; vocab read from the tokenizer, never hardcoded.
  Default D3LM-R for generation (paper's best generator).
- **SFID** requires Sei; without it we report GC ratio (Chargaff parity, strongly discriminative:
  D3LM-R 1.07 vs collapsed Evo 0.86 / P2 12.7), diversity, novelty, and motif correlation — all real.
- **transformers pinned `<4.46`** (custom `diffusion_generate` remote code, like Caduceus/DNAGPT); a
  from-scratch reverse-unmasking fallback drives the plain masked-LM forward if the bundled sampler breaks.
