# Dataset Instructions

This repository uses several tabular datasets as evaluated in the paper:
- CCPP
- QSAR fish toxicity
- Real estate
- Yacht hydrodynamics
- Fertility

## How to obtain

These datasets are publicly available from the UCI Machine Learning Repository or similar sources.

Please download the datasets and place them in the `data/raw/` directory.

Example structure:
```text
data/raw/
  ccpp/
    Folds5x2_pp.csv
  qsar_fish_toxicity.csv
  real_estate.csv
  yacht_hydrodynamics.data
  fertility_Diagnosis.txt
```
